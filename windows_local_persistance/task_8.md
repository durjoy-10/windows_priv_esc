# 🌐 টাস্ক ৮: বিদ্যমান সার্ভিসের মাধ্যমে পার্সিস্টেন্স (Persisting Through Existing Services)

## 📌 ভূমিকা ও সাধারণ ধারণা

**ধারণা:** উইন্ডোজের বিল্ট-ইন ফিচার ব্যবহার না করে, সিস্টেমে আগে থেকে চলমান কোনো সার্ভিসকে কাজে লাগিয়ে ব্যাকডোর স্থাপন করা। এটি আরও স্টিলথ (গোপন) পদ্ধতি কারণ কোনো নতুন সার্ভিস বা শিডিউল্ড টাস্ক তৈরি করতে হয় না। এই টাস্কে একটি ওয়েব সার্ভার এবং MSSQL ডাটাবেস সার্ভারকে কাজে লাগিয়ে পার্সিস্টেন্স তৈরির দুটি পদ্ধতি দেখানো হয়েছে।

**কেন এই পদ্ধতি কার্যকর?**
- কোনো নতুন সার্ভিস তৈরি হয় না (ইভেন্ট লগে কম সন্দেহ)
- বৈধ সার্ভিসের মাধ্যমেই পেলোড চালানো হয়
- ব্লু টিম সাধারণত ওয়েব ডিরেক্টরি বা ডাটাবেস ট্রিগার মনিটর নাও করতে পারে

**এই টাস্কে দুইটি পদ্ধতি আলোচনা করা হয়েছে:**
1. **ওয়েব শেল (Web Shell)** - IIS ওয়েব সার্ভারে ASPX শেল আপলোড
2. **MSSQL ব্যাকডোর (MSSQL as a Backdoor)** - ডাটাবেস ট্রিগারের মাধ্যমে পেলোড চালানো

## 🌍 পার্ট ১: ওয়েব শেল ব্যবহার (Using Web Shells)

### তাত্ত্বিক ব্যাখ্যা
ওয়েব সার্ভারে পার্সিস্টেন্সের সবচেয়ে সহজ পদ্ধতি হলো ওয়েব ডিরেক্টরিতে একটি ওয়েব শেল আপলোড করা। IIS-এ ডিফল্ট ইউজার `iis apppool\defaultapppool` হয়, যার `SeImpersonatePrivilege` নামক বিশেষ সুবিধা থাকে। এই সুবিধা কাজে লাগিয়ে সহজেই অ্যাডমিনিস্ট্রেটরে প্রিভিলেজ এস্কেলেশন করা যায়।

### ধাপে ধাপে নির্দেশনা

| ধাপ | কমান্ড / কাজ | ব্যাখ্যা |
|:---:|:---|:---|
| ১ | ওয়েব শেল ডাউনলোড করো (অ্যাটাকার মেশিন থেকে) | একটি ASPX ওয়েব শেল (যেমন `shell.aspx`) সংগ্রহ করো |
| ২ | ভিক্টিম মেশিনে ট্রান্সফার করো | HTTP, SMB, বা অন্য যেকোনো উপায়ে |
| ৩ | ওয়েবরুট ডিরেক্টরিতে মুভ করো | `move shell.aspx C:\inetpub\wwwroot\` |
| ৪ | পারমিশন ঠিক করো (যদি দরকার হয়) | `icacls C:\inetpub\wwwroot\shell.aspx /grant Everyone:F` |
| ৫ | ব্রাউজারে শেল অ্যাক্সেস করো | `http://<MACHINE_IP>/shell.aspx` |
| ৬ | ফ্ল্যাগ রান করো | ওয়েব শেল থেকে `C:\flags\flag16.exe` এক্সিকিউট করো |
| | **ফলাফল** | **ফ্ল্যাগ ১৬:** `THM{EZ_WEB_PERSISTENCE}` |

### কমান্ড একনজরে
```cmd
move shell.aspx C:\inetpub\wwwroot\
icacls C:\inetpub\wwwroot\shell.aspx /grant Everyone:F
```

### গুরুত্বপূর্ণ নোট
* IIS-এর ডিফল্ট ওয়েবরুট: C:\inetpub\wwwroot\

* পারমিশন এরর পেলে Everyone:F দিয়ে ফুল অ্যাক্সেস দাও

* ওয়েব শেল থেকে whoami /priv দিয়ে SeImpersonatePrivilege চেক করা যায়

### ডিটেকশন ঝুঁকি
* ব্লু টিম ওয়েব ডিরেক্টরির ফাইল ইন্টিগ্রিটি চেক করতে পারে

* নতুন ফাইল অ্যাড হলে অ্যালার্ট ট্রিগার হতে পারে

* ফাইল টাইমস্ট্যাম্প পরিবর্তন মনিটর করা হতে পারে
